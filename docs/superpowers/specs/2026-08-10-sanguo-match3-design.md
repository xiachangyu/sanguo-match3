# 三国消消乐 — 微信小游戏设计文档

- 日期：2026-08-10
- 状态：已确认（待实现）
- 技术栈：原生微信小游戏（JavaScript + Canvas），零第三方依赖

---

## 1. 概述

一款以《三国演义》为题材的文字三消微信小游戏。核心特色：**基础字块三消** + **三国故事短语连字**双玩法。每通关一个故事关就解锁该故事的字块加入公共字池，字池随进度不断扩充；每个故事还附带一个初始技能和更强版的觉醒技能（精英模式解锁），形成轻度养成。

## 2. 核心玩法

### 2.1 基础操作：互换三消
- 8×8 棋盘，字块类型为基础字块（兵、弓、车、枪、骑）。
- 点击一个字块与相邻（上下左右）字块互换，横/竖 3 个及以上相同字即消除。交换播放**滑动动画**：先交换过去再判定，成三连则白闪缩放消除 + 下落补字（连锁继续），**未成三连自动滑回原位**。动画期间锁定输入。
- **特殊字块**（借鉴开心消消乐）：消除形成 4 连 → 生成**横/纵线炸弹**（点击清除整行/整列，方向与连线一致）；5 连 → **全屏彩虹炸弹**（点击全屏清除）；T/L 形（≥5 格交叉）→ **3×3 炸弹**。特殊字块**点击即引爆**（金色边框 + 角标标识），引爆后可再连锁，连锁中可继续生成新特殊块。
- 4 连、5 连、连锁消除有额外加分。
- 消除后字块下落，从当前字池随机补字。

### 2.2 进阶操作：故事短语连字
- 盘面上出现已解锁故事的字块（每盘随机挑 2~3 个已解锁故事上场）。
- 玩家一笔划过**同一行或同一列上相邻**的字块，路径字块集合恰好是该故事短语（**顺序不限**，如「义结三园桃」也算桃园三结义）→ 整组消除 + 触发该故事技能。
- **武将划线**：通关故事关解锁该关关联武将。每个武将有名字（收集/展示）与**绝技词**（3~5 字，如刘备「仁德天下」）——绝技词的字块作为盘面字块，玩家一笔划过相邻直线、字块集合恰好为该绝技词即命中武将。命中后按"是否按顺序"与"是否已觉醒"决定技能：**已觉醒且按顺序划（正序/逆序，四方向）→ 触发觉醒技能；否则（未觉醒或乱序）→ 触发初始技能**；同时**显示专属台词横幅**并播放音频/专属音效，计入武将收集。乱序也触发（初始效果），不会无效。

### 2.3 过关条件（目标多样化）
- 普通关目标按 **分数 → 收集 → 短语** 三类轮换（每 3 关一个循环，数值随阶段递增）：限时达分 / 限时收集某基础字 N 个 / 限时触发故事短语 N 次；精英关固定为分数目标。
- 达成目标即过关；时间耗尽未达标则失败。
- 失败可重试（再扣 5 体力）或退出回大厅。
- 消除时飘出得分与连击反馈文案（4 连「好！」5 连「太棒了！」T/L「神了！」连锁「连击 ×N」）。

## 3. 大厅与进度

- **大厅**只有一个「开始闯关」按钮：扣 5 体力 → 进入当前关。
- **图鉴**（大厅右下角入口）：**以武将及其技能为主体**。过关解锁武将后，图鉴详情显示每个武将的「名字 · 绝技词 · 技能（初始/觉醒）」；故事名仅作为顶部小标题背景，下方另附故事的初始/觉醒技能（保留故事短语玩法）。大厅解锁预告也显示对应武将名。
- 界面**右上角**显示解锁预告，例如玩家在 2~4 关时显示「第 5 关解锁：温酒斩华雄」。
- 故事关 = 普通关 + 开局剧情简介 + 该故事字块出现率翻倍。**未解锁的故事字块不会出现在盘面**：通关故事关后才解锁该故事，其字块从下一关起进入公共字池、每盘随机挑 2~3 个已解锁故事上场（同一故事字块也可在该故事已解锁时的关卡出现）。

- **技能触发模型**：每个故事的初始技能靠划出该故事短语触发；觉醒技能为更强版本，通关对应精英关后**替换**初始技能（同一触发方式，效果更强，不叠加）。
- **技能表**（数据驱动，加技能只改 skills.js 配置）：

| 故事 | 初始技能 | 觉醒技能（精英解锁） |

## 6. 精英模式

- 每一关都有精英版，独立进度，从第 1 关开始。
- 精英关需先通关对应普通关才能玩。
- 规则：时间更短（40 秒）、目标分更高（×1.5）。
- 通关精英关 → 解锁该关故事的**觉醒技能**。

## 7. 广告与分享系统

### 7.1 激励视频广告
- **①补体力**：体力不足时看激励视频 +10 体力，每日限 5 次。
- **②失败续命**：时间耗尽失败时看激励视频续 15 秒，每关限 1 次。
- **③广告给道具**：看激励视频得 1 个随机道具，每日限 3 次。
- 技术：`wx.createRewardedVideoAd({adUnitId})`，广告位 ID 在 `ads.js` 配置（微信公众平台「流量主」开通后填入占位），需处理加载失败 / 拉取失败。

### 7.2 分享
- **分享给道具**：每日首次分享到微信群 / 好友得 1 个随机道具。
- 技术：`wx.shareAppMessage()`，分享后回调发放奖励，每日计数记录在存档。

## 8. 道具系统

| 道具 | 效果 |
|------|------|
| 铁锤 | 砸掉盘面任意一个字块 |
| 置换 | 任意两个字块互换位置 |
| 洗牌 | 重排整个盘面 |
| 加时 | +10 秒时间 |

- 闯关中点击道具图标消耗一个；库存存于存档。
- 获取渠道：分享给道具（每日首次）、广告给道具（每日 3 次）。

## 9. 技术架构（模块化）

```
main.js     入口 + 游戏循环 + 状态机(大厅/闯关中/结算)
  ├── board.js     棋盘生成、互换、消除、下落、补字
  ├── match3.js    三/四/五连判定、连锁
  ├── story.js     故事字块、一笔划线判定
  ├── skills.js    技能定义与执行（数据驱动）
  ├── levels.js    关卡配置表(目标分/时间/解锁/字池)
  ├── elite.js     精英模式规则
  ├── ui.js        Canvas 绘制(大厅/棋盘/右上角预告/计分)
  ├── ads.js       激励视频广告(补体力/续命/道具) 配置与封装
  └── storage.js   本地存档
```

- **数据流**：输入 → board 互换 → match3 判定 → 消除得分 → 下落补字 → 连锁 → UI 渲染。
- **状态机**：`LOBBY`（大厅）→ `PLAYING`（闯关中）→ `RESULT`（结算）；普通 / 精英两条进度轨道。
- **存档字段**（`wx.setStorageSync`）：`currentLevel`、`eliteLevel`、`stamina` + 上次恢复时间戳、`unlockedStories`（解锁/觉醒标记）、`props`（道具库存：铁锤/置换/洗牌/加时）、`dailyCounters`（每日广告/分享次数）、`highScores`、`settings`。

## 10. 错误处理

- 体力不足 → 提示 + 「看广告补体力」或「等待恢复」入口。
- 广告拉取 / 加载失败 → 隐藏广告按钮或提示「广告加载中，稍后再试」，不影响正常游戏流程。
- 棋盘无解（无可互换能形成三连）→ 自动检测并洗牌一次。
- 存档缺失 / 损坏 → 重置为初始状态并提示。
- 屏幕适配 → `wx.getSystemInfoSync()` 取屏幕尺寸动态计算格子大小。

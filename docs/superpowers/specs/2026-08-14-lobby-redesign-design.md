# 大厅与对局界面改版 — 设计文档

- 日期：2026-08-14
- 状态：已确认（待实现）
- 前置：`2026-08-10-sanguo-match3-design.md` 的功能设计不变，本次仅调整界面呈现与广告/分享入口位置

---

## 1. 背景

原大厅为纯色绿底 + 平铺文字按钮，视觉单调（用户反馈"效果很一般"）。同时"广告得道具 / 分享得道具"入口放在大厅底部，占用主视觉空间。

本次改版目标：
1. 大厅换成**水墨纸卷**风格，贴合三国题材，提升质感。
2. 体力移到左上角；去掉大厅里的广告/分享按钮。
3. 广告/分享得道具入口**挪到对局界面的棋盘下方空闲区**，两个按钮并排。

## 2. 大厅（水墨纸卷风）

### 2.1 背景与装饰
- 背景：米白宣纸渐变（`#f5eddc` → `#efe2c8`）。
- 底部装饰：远山墨影——下半部墨绿渐隐 + 底部圆角山形（`#3a4b41`，低透明度），纯装饰不响应点击。

### 2.2 标题
- 墨色大字「三国消消乐」（深色 `#2c2c28`，字间距拉开）。
- 右上角跟随一个朱砂红小字「汉」做印章感（旋转 6° 装饰）。
- 标题下方一条渐隐装饰横线。

### 2.3 体力（左上角）
- 左上角胶囊标签：米白半透明底 + 细描边，文字「体力 30/30」。

### 2.4 关卡进度
- 「关卡进度 · 第 N 关」小字。
- 进度条：米黄轨道，墨色填充。填充比例按里程碑区间插值：`fill = clamp((level - prevMilestone) / (nextMilestone - prevMilestone), 0, 1)`，其中 `prevMilestone` 为 ≤ level 的最近解锁关（无则 0），`nextMilestone` 为 > level 的下一个解锁关（无则用下一关）。
- 条下方里程碑刻度：显示 1 / 5 / 10 / 20（随进度延伸，最多显示到 nextMilestone）。
- 解锁预告小牌：米白底 + 细描边 + **朱砂红左边条**，文字「下一关 · 第 5 关解锁「温酒斩华雄」」（复用现有 `levels.getUnlockPreview` + `story.getStory`，基于 `state.currentLevel`）。

### 2.5 按钮
- 「开始闯关」：朱砂红渐变（`#d1493b` → `#b23a2e`），下投影 3px，米白粗体字。
- 「精英模式 · 第 N 关」：半透明白底 + 墨灰描边，墨灰字。

### 2.6 删除
- 大厅不再绘制广告 / 分享按钮及其命中区域。

## 3. 对局界面（保持现有风格）

- 棋盘下方、道具栏上方空闲区新增两个并排按钮：
  - **「📣 广告」**：黄色渐变（`#ffd54f` → `#ffb300`），点击逻辑复用现有 `ads.showPropAd()`。
  - **「🎁 分享」**：蓝色渐变（`#4fc3f7` → `#039be5`），点击逻辑复用现有 `ads.showShare()`。
- 其余 HUD（关卡/目标/时间/分数）、棋盘、道具栏、体力、选中高亮均不动。

## 4. 交互与命中区域

- `ui.lobbyButtons()` 去掉 `adProp` / `share` 两个矩形；新增 `lobbyStaminaRect`（左上角体力标签，可点击弹「体力不足看广告」或暂不响应——见 6）。
- 对局界面新增 `playingAdBtns(w, h)` 返回两个并排按钮矩形，`main.js` 的 `onTap` 在 PLAYING 分支优先命中道具栏之前先命中广告/分享按钮。

## 5. 测试

- 纯函数逻辑（广告/分享发放、体力）无改动，现有 `npm test` 应保持 48/48 通过。
- 手动验证：
  1. 大厅显示水墨纸卷风、体力左上角、无广告/分享按钮。
  2. 对局界面棋盘下方两按钮并排，点击分别触发广告/分享得道具。
  3. 不同屏幕尺寸（窄屏/宽屏）下按钮不遮挡棋盘与道具栏。
